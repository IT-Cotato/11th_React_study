# 11기 리액트 스터디
IT 연합동아리 코테이토 소속 리액트 라이브러리 스터디입니다.  
각자 원하는 리액트 강의를 선정하고 10주 완강 계획을 공유합니다.  
주차별로 정해진 강의를 수강하며 학습한 내용을 조사 및 정리하여 스터디 시간에 발표를 통해 공유합니다.

## RULE
1. 주차에 해당하는 강의를 수강한다. 
2. 강의를 수강하며 추가 학습한 내용을 조사 및 정리한다. 양식은 자유입니다!
    
    [필수] 깃허브 레포 markdown
    
    [선택] 개인 노션 or 기술 블로그
3. 스터디 참석 (중간/기말 해당 팀원 제외)
    
    3-1. 본인이 공부한 내용을 돌아가면서 설명한다. 
    
    3-2. 강의를 수강하며 이해가 어려운 부분이나 오류를 공유한다.
