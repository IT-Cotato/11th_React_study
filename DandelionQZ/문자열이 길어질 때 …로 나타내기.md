```jsx
const 함수명 = (str, n) => {
	return str?.length > n ? str.substr(0, n-1) + "..." : str;
}
```

삼항연산자를 이용해서 str의 길이가 n 보다 클 때만 문자열을 자르고 …를 붙일 수 있게 한다.

문자열을 자르는 javascript의 메서드에는 대표적으로 3가지가 있다.

### slice(from, to) - from 이상 to 미만 출력
- from : 시작점의 index
- to : 끝점의 index (미지정시 끝까지 출력)
- 음수인 경우 : 문자열 끝에서부터 인덱스의 시작을 의미
    
### substring(from, to) - from 이상 to 미만 출력
- from : 시작점의 index
- to : 끝점의 index (미지정시 끝까지 출력)
- 음수인 경우 : 문자열 0을 의미

### substr(start, length) - from부터 n번째까지 출력
- from : 시작점의 index
- to : 문자열의 길이 (미지정시 끝까지 출력)
- 음수인 경우 : 문자열 길이에서 음수를 뺀 수가 index 값을 의미
 
### 문자열이 아닌 배열 관련 메서드 
- split(value) - value를 기준으로 문자열을 분리하여 배열에 담아서 반환
- splice(from, to) - from 이상 to 미만 값의 배열 요소를 반환
  - 문자열이 아닌 배열을 자르는 메서드
