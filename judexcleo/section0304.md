## Node.js
### 1. 프로젝트 초기화 및 실행
- `npm init`: `package.json` 파일 생성 (프로젝트 정보 및 의존성 관리)
- `node index.js`: `index.js` 파일 실행

### 2. 모듈 시스템

#### 모듈이란?
- 복잡한 기능을 하나의 파일에 작성하면 관리가 어려움
- 기능별로 파일을 나누어 개발 → **각각의 파일을 모듈**이라고 함

#### 모듈 시스템이란?
- 모듈을 다루는 다양한 기능을 제공하는 시스템

### 3. 라이브러리란?
- 프로그램 개발에 필요한 다양한 기능을 **미리 만들어 모듈화**해 놓은 것
- 예시: [npmjs.com](https://www.npmjs.com) 에서 다양한 라이브러리를 검색 및 설치 가능

## React

### 1. React란?
- Meta(구 Facebook)가 개발한 **오픈소스 JavaScript 라이브러리**
- **대규모 웹 서비스의 UI**를 더 편하게 개발하기 위해 만들어짐

### 2. React 특징
1. **컴포넌트 기반으로 UI를 표현**
2. **화면 업데이트 구현이 쉬움**
3. **화면 업데이트가 빠르게 처리됨**

---

### 3. React의 주요 개념

#### (1) 컴포넌트 기반 UI
![](https://velog.velcdn.com/images/tmdgml110806/post/043d8a2e-fa1a-47f2-a13c-68e7eb4a06bc/image.png)
- UI를 여러 개의 **컴포넌트**로 나누어 개발
- 각 컴포넌트는 **모듈화**되어 재사용 가능
- 유지보수에 유리하며, 중복 코드를 줄일 수 있음

#### (2) 화면 업데이트 구현이 쉬움
- **선언형 프로그래밍** 방식 사용  
  → 이루고자 하는 목적만 명시 (과정은 생략)  
  → React는 이 방식을 따름  
- (반대) **명령형 프로그래밍**  
  → 목적을 이루기 위한 모든 과정을 상세히 설명 (JavaScript 전통 방식)

#### (3) 화면 업데이트가 빠르게 처리됨
![](https://velog.velcdn.com/images/tmdgml110806/post/24456f03-5713-47f4-9efb-bc42b53a77aa/image.png)
- 브라우저에서 **layout, painting** 과정은 시간이 오래 걸림
- **JavaScript**: DOM 수정을 최소화하여 성능 개선  
  → 동시에 발생한 업데이트를 모아서 **한 번에 DOM 수정**ㅎㅐㅇㅑ
- **React**: 이를 자동으로 처리  
  → **Virtual DOM** 사용  
  → 실제 DOM 대신 Virtual DOM을 수정  
  → 업데이트가 모이면 **한 번에 실제 DOM에 반영** (DOM 수정 최소화)

## React 프로젝트 생성 및 실행

### 1. Vite를 이용한 React 프로젝트 생성
- `npm create vite@latest`: Vite 기반 React 프로젝트 생성
- `npm install` 또는 `npm i`: `package.json`의 정보를 기반으로 라이브러리 설치
- `npm run dev`: 개발 서버 실행

### 2. 개발 서버와 포트번호
- React 앱에는 **웹 서버**가 내장되어 있음
- `npm run dev` 실행 시 **웹 서버가 가동**됨
- `localhost:<포트번호>`  
  → `localhost`: 내 컴퓨터  
  → `<포트번호>`: 특정 서버를 구분하기 위한 번호  
  → 하나의 PC에서 여러 서버가 실행될 수 있기 때문에 **포트번호로 서버를 구분**
