## 1. React에서의 리렌더링 이슈

* 리액트 컴포넌트는 **부모가 리렌더링되면 자식도 리렌더링**
* **불필요한 리렌더링은 성능 저하**로 이어질 수 있음
* props가 변하지 않았음에도 자식 컴포넌트가 재생성되는 경우가 많음

---

## 2. React.memo

### 개념

* 고차 컴포넌트(HOC)로, **컴포넌트의 props가 변경되지 않으면 리렌더링을 방지**함.
* React의 `PureComponent`와 유사.

### 사용 예시

```jsx
const Child = React.memo(({ name }) => {
  return <div>{name}</div>;
});
```

### 특징

* \*\*props 비교는 얕은 비교(shallow comparison)\*\*로 진행됨.
* **함수, 객체, 배열 등은 매번 새로 생성되므로 주의 필요**.

---

## 3. useMemo

### 개념

* **비싼 연산의 결과를 메모이제이션**하여, 의존성 배열이 변경되지 않으면 기존 값을 재사용함.

### 사용 예시

```jsx
const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);
```

### 사용 시점

* 연산 비용이 높은 경우.
* 동일한 연산 결과를 재사용하고자 할 때.

---

## 4. useCallback

### 개념

* 함수를 메모이제이션하여 **컴포넌트가 리렌더링되어도 동일한 함수 인스턴스를 유지**함.

### 사용 예시

```jsx
const memoizedCallback = useCallback(() => {
  doSomething(a, b);
}, [a, b]);
```

### 사용 시점

* 자식 컴포넌트에 **함수를 props로 넘길 때**.
* 함수의 재생성을 방지하고 싶은 경우.

---

## 5. 세 가지의 차이점 정리

* useMemo : 값의 계산을 메모리제이션해서, 값이 편경될 때만 재계산한다. 주로 비싼 계산을 최적화할 때 사용한다

* useCallback : 함수를 메모리제이션하여, 함수가 의존성 배열의 값이 변경도리 때만 새로 생성한다. 주로 자식 컴포넌트에 함수를 전달할 때 사용한다

* React.memo : 컴포넌트를 메모리제이션하여, props가 변경되지 않으면 컴포넌트가 리렌더링되지 않도록 최적화한다
